A Roc machine

One Roc value holds the devices: memory, PCI configuration space, a drive, a keyboard queue, a console. A hand-written Roc program scans PCI bus 0 through ports 0xCF8/0xCFC, reads sector 0 through the block door into memory, then echoes the keys you type. The drive is upstream's block-select-drives.disk.
