# Allocations and reallocations a pass each control is held to in the dev
# build (--opt=dev), and why when either is not 0:
# `<control> <allocs> <reallocs> <why>`. A control not listed here is held to
# 0 and 0. Measured on Roc 0.1.0-RC1 by js/controls.shale opt=dev. The dev
# build lowers closures and the like to boxes, as --specialize=no does, so
# it allocates where the release build (expected.txt) doesn't.
00-loop 1 0 the empty block `{}` the loop runs, which the release build doesn't make; the other controls' bodies are statements, not blocks
02-closure-call 3 0 the call, none of them in the release build
05-array-push 2 0 the release build's one (the argument list) and one more for the call
06-push-pop 4 0 05-array-push's two for the push and two for the pop, none of the pop's in the release build
