Steve's Roc Apps

Fast Track

Three computer players, written in Roc, try every line of play through the rest of their turn and take the one their strategy scores highest, and they never see a card they haven't drawn.

The marble race board game: you play red against them, and their marbles walk the board as they move. The rules and the whole page are Roc, ported from Steve's Elm version; the computer players are new.

Safari Ride

A whole countryside built in Roc, frame by frame: hills, a winding road, herds, a cat and a bird, and a rider who leans into the turns.

A drive through the country, as a screensaver. Space pauses, the arrows step through the ride, J jumps to the next intersection, R starts over. The same files run here and as a native program.

Safari Ride: a tour of a real Roc program

A little book that teaches Roc through Safari Ride's real source: every snippet is quoted from the program when the book is built, so the book and the code never drift apart.

It starts from one page of the ride and works out to the whole program: types, tag unions, records, opaque types, pure functions and effects, each met where the ride needs it. Interactive widgets let you poke at the pieces. An early draft.

roc-markdown

A markdown renderer in pure Roc that's safe to show whatever a user typed, with a hard limit on the work any one message can cost.

Messages to HTML: a Roc package with no dependencies and no platform, pure functions from bytes to bytes, so any Roc app can import it. It renders Gopher Chat on lynrummy.com. The playground runs it, compiled to WebAssembly, as you type.

BASIC

A BASIC interpreter written by hand in Roc, graded against the National Bureau of Standards' Minimal BASIC test programs and the classic games of 1978.

It runs two dialects: ECMA-55 Minimal BASIC, and the BASIC of the 1978 Creative Computing games. The REPL runs here; the same interpreter runs as a native program.
