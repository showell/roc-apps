Steve's Roc Apps

Programs that run in this tab. Each is mostly Roc, compiled to WebAssembly on a platform written for it, with a thin layer of JavaScript that loads it, draws what it answers, and hands it the clicks and keys. Some of them also run as native programs.

Board Games

Fast Track

The marble race: you play red against three computer players, and their marbles walk the board as they move. Ported from Steve's Elm version of the game; the computer players are new, searching every way to play their turn through the game's own rules and keeping the one they value most.

Steve's Elm originalHow it is built

Canvas apps

Small interactive programs, each one a Roc value: a size, a rate, a way to step it with the keyboard and the pointer, and a frame of shapes to draw. Most of them are roc-ray's own examples, by Luke Boswell, taken with only small changes to fit this scheme. The same files run here and as native programs through roc-ray — the README says how to build those.

Safari

A drive through the country, as a screensaver: the rider leans into the turns and the animals cross when they like. Space pauses, the arrows step through the ride, J jumps to the next intersection.
