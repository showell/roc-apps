Chapter 4

Deciding in plain Python

A problem is four answers, one per input, so deciding one takes a line of ordinary code. The code here is python/decides.py, which build.shale runs on every build: it holds its two versions to each other on all 16 problems and all four inputs, and each one-line test below to its problem.

What the machine adds §

The want code already says everything about a problem. The Nibble machine takes up to six lines to say the same thing, and for {0, 2, 3} it takes all six, in its one program. The composed polynomial of “Six steps composed”, which runs every program on every input at once, takes 10,324 terms. The machine is there to be the thing analysed, a small checker that Cook and Levin's construction can turn into a formula; the question it answers is a lookup.
