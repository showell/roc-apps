Nibble puzzles

Nibble is the language of a tiny machine. It has one register, AX, which holds 0, 1, 2 or 3, and a program is exactly six instructions. A run starts with AX set to the input. It accepts when zero finds AX at 0, and it rejects when decr finds AX at 0 or when it runs off the end. Each puzzle names a set of inputs: write a program that accepts exactly those. The first five puzzles teach you Nibble, one opcode at a time.
