Under the hood

Both toys are one architecture. Tape.roc is the shared engine: a search emits an event tape (place a piece, remove a piece, one byte a move) and the display just walks a cursor over that tape, applying moves forward or undoing them backward. That single idea is what makes every animation pausable and scrubbable in both directions: rewinding is not a feature bolted onto the search, it falls out of the data. The engine also owns the red overlay: a square where a piece was placed, found doomed, and pulled off ("empty and once touched", which are the same thing, because a square's moves strictly alternate place and remove).

The search itself is shared too. Backtrack.roc is depth-first backtracking in 30 lines, for any puzzle that can say where the option at an index leads from a state, or refuse it. Its frames are values, so backing up only drops the top frame: nothing is undone by hand. Each step enters a state, leaves one, or finds the root out of options, and a toy turns those into tape moves.

Each toy is then just a machine: Knight.roc builds the knight-move graph and states the tour as a puzzle for that search; Queens.roc states the classic row-by-row eight-queens puzzle with column and diagonal bitmasks. A machine answers four things: how many pieces mean solved, its next move (one search transition, one event), how it starts from the clicked square, and its own "impossible right now" overlay (the indigo squares: unreachable for the knight, attacked for the queens). ChessApp.roc takes a machine and makes the page, so the toys cannot drift apart.

Everything above is Roc, compiled to WebAssembly. The browser's side is two small files every canvas app here shares: canvas_app_runner.js keeps the clock, the keys and the pointer, and shapes_canvas.js paints the shapes the Roc answers each frame. These are the exact sources the pages are built from. Also on GitHub.

The shared search: depth-first backtracking, a transition at a time, for any puzzle.

## Backtrack is depth-first search, a transition at a time, for any puzzle that
## says where the option at an index leads from a state. Each frame is a state
## and where its parent resumes; states are values, so backing up drops a frame.
Backtrack(state) :: { frames : List({ state : state, after : U64 }), next : U64 }.{

	## A puzzle: the state the option at an index leads to, refused, or the end.
	Puzzle(state) : state, U64 -> [Child(state), Refused, End]

	## A state entered, the top state left, or the root out of options.
	Change(state) : [Entered(state), Left(state), Exhausted]

	## The search from its root, `state`.
	start : state -> Backtrack(state)
	start = |state| Backtrack.({ frames: [{ state, after: 0 }], next: 0 })

	## The search one transition on, and the change it made.
	step : Backtrack(state), Backtrack.Puzzle(state) -> (Backtrack(state), Backtrack.Change(state))
	step = |Backtrack.({ frames, next }), puzzle| {
		top = frames.last() ?? crash "Backtrack.step: a search holds its root"
		match puzzle(top.state, next) {
			Child(state) => {
				entered = frames.append({ state, after: next + 1 })
				(Backtrack.({ frames: entered, next: 0 }), Entered(state))
			}
			Refused => Backtrack.({ frames, next: next + 1 }).step(puzzle)
			End if frames.len() == 1 => (Backtrack.({ frames, next }), Exhausted)
			End => (Backtrack.({ frames: frames.drop_last(1), next: top.after }), Left(top.state))
		}
	}
}

The shared engine: the event tape, the scrubbing display, and the red overlay.

## Tape is the engine both chess toys run on. A search speaks only by
## appending moves to an event tape, one byte a move: the top bit says
## whether a piece was placed or removed, and the low six bits name the
## square. The board a viewer sees is a cursor walking that tape, applying
## each move forward or undoing it backward, so pausing, stepping and
## scrubbing in both directions fall out of the data. A remove always takes
## the newest piece, so every move undoes itself.
##
## The red overlay lives here too. A square is a dead end when a piece placed
## there was found doomed and pulled off, and none has come back since. It is
## marked when the piece is retracted, never predicted, so marks build up as a
## doomed branch unwinds and a square clears when the search enters it again.
## A square's moves alternate place and remove, so a dead end is exactly an
## empty square that some move before the cursor touched: one count a square,
## kept in both directions.
Tape :: {
	events : List(U8),
	cursor : U64,
	board : List(I8),
	pieces_shown : U64,
	touches : List(U32),
	search : [Waiting, Running, Solved, Exhausted],
	target_count : U64,
	pieces_at_end : U64,
	deepest : U64,
}.{

	## What a search does at one transition: place a piece, take the newest
	## one off, take it off and stop because nothing is left to try, or stop
	## with nothing to take off.
	Move : [Place(U8), Remove(U8), RemoveAndGiveUp(U8), GiveUp]

	## Where a search stands at the tape's end. `Waiting` is the board before
	## anyone has clicked.
	Search : [Waiting, Running, Solved, Exhausted]

	## A tape moved one step forward, with the machine that may have made the
	## move, and whether the board moved.
	Stepped(machine) : { tape : Tape, machine : machine, step : [Moved, Stuck] }

	## The board before any search: empty, with nothing on the tape.
	empty : Tape
	empty = Tape.(empty_parts)

	## A new search whose first piece is on `square`, already shown, which is
	## solved when `target_count` pieces stand on the board.
	start : { square : U8, target_count : U64 } -> Tape
	start = |{ square, target_count }| {
		running = Tape.({ ..empty_parts, search: Running, target_count })
		placed = running.with_move(Place(U8.bitwise_and(square, square_bits)))
		match placed.step_forward() {
			Ok(shown) => shown
			Err(AtEnd) => crash "Tape.start: the first piece was appended and could not be shown"
		}
	}

	## The tape with `move` appended at its end. The display doesn't move.
	with_move : Tape, Tape.Move -> Tape
	with_move = |Tape.(tape), move|
		match move {
			Place(square) => {
				at_end = tape.pieces_at_end + 1
				search =
					if at_end == tape.target_count {
						Solved
					} else {
						tape.search
					}
				Tape.(
					{
						..tape,
						events: tape.events.append(U8.bitwise_or(place_bit, square)),
						pieces_at_end: at_end,
						deepest: U64.max(tape.deepest, at_end),
						search,
					},
				)
			}
			Remove(square) => Tape.({ ..tape, events: tape.events.append(square), pieces_at_end: tape.pieces_at_end - 1 })
			RemoveAndGiveUp(square) =>
				Tape.(
					{
						..tape,
						events: tape.events.append(square),
						pieces_at_end: tape.pieces_at_end - 1,
						search: Exhausted,
					},
				)
			GiveUp => Tape.({ ..tape, search: Exhausted })
		}

	## Whether the next step forward needs a new move: the cursor is at the
	## tape's end, the search still runs, and the tape has room.
	should_generate : Tape -> Bool
	should_generate = |Tape.(tape)|
		tape.cursor == tape.events.len()
			and tape.events.len() < capacity
			and match tape.search {
				Running => Bool.True
				Waiting | Solved | Exhausted => Bool.False
			}

	## One step forward on the display. At the tape's end, while the search
	## runs, `next_move` makes the move first. The board doesn't move once the
	## search is solved or spent and the cursor has reached the end.
	forward : Tape,
	{
		machine : machine,
		next_move : machine -> (machine, Tape.Move),
	} -> Tape.Stepped(machine)
	forward = |tape, { machine, next_move }| {
		(made, moved_machine) =
			if tape.should_generate() {
				(machine_after, move) = next_move(machine)
				(tape.with_move(move), machine_after)
			} else {
				(tape, machine)
			}
		match made.step_forward() {
			Ok(stepped) => { tape: stepped, machine: moved_machine, step: Moved }
			Err(AtEnd) => { tape: made, machine: moved_machine, step: Stuck }
		}
	}

	## The display one move further along the tape, or `AtEnd` when it shows
	## every move there is.
	step_forward : Tape -> Try(Tape, [AtEnd])
	step_forward = |Tape.(tape)|
		match tape.events.get(tape.cursor) {
			Err(OutOfBounds) => Err(AtEnd)
			Ok(event) => {
				square = U8.bitwise_and(event, square_bits).to_u64()
				touched = tape.touches.get(square) ?? crash "Tape.step_forward: a square past the board"
				if U8.bitwise_and(event, place_bit) != 0 {
					Ok(
						Tape.(
							{
								..tape,
								cursor: tape.cursor + 1,
								touches: tape.touches.set(square, touched + 1) ?? crash "Tape.step_forward: a square past the board",
								board: tape.board.set(square, move_number(tape.pieces_shown)) ?? crash "Tape.step_forward: a square past the board",
								pieces_shown: tape.pieces_shown + 1,
							},
						),
					)
				} else {
					Ok(
						Tape.(
							{
								..tape,
								cursor: tape.cursor + 1,
								touches: tape.touches.set(square, touched + 1) ?? crash "Tape.step_forward: a square past the board",
								board: tape.board.set(square, -1) ?? crash "Tape.step_forward: a square past the board",
								pieces_shown: tape.pieces_shown - 1,
							},
						),
					)
				}
			}
		}

	## The display one move back, undoing it, or `AtStart` at the tape's
	## first move.
	step_back : Tape -> Try(Tape, [AtStart])
	step_back = |Tape.(tape)|
		if tape.cursor == 0 {
			Err(AtStart)
		} else {
			cursor = tape.cursor - 1
			event = tape.events.get(cursor) ?? crash "Tape.step_back: the cursor is past the tape"
			square = U8.bitwise_and(event, square_bits).to_u64()
			touched = tape.touches.get(square) ?? crash "Tape.step_back: a square past the board"
			if U8.bitwise_and(event, place_bit) != 0 {
				Ok(
					Tape.(
						{
							..tape,
							cursor,
							touches: tape.touches.set(square, touched - 1) ?? crash "Tape.step_back: a square past the board",
							board: tape.board.set(square, -1) ?? crash "Tape.step_back: a square past the board",
							pieces_shown: tape.pieces_shown - 1,
						},
					),
				)
			} else {
				Ok(
					Tape.(
						{
							..tape,
							cursor,
							touches: tape.touches.set(square, touched - 1) ?? crash "Tape.step_back: a square past the board",
							board: tape.board.set(square, move_number(tape.pieces_shown)) ?? crash "Tape.step_back: a square past the board",
							pieces_shown: tape.pieces_shown + 1,
						},
					),
				)
			}
		}

	## The board shown: a move number for each of the 64 squares, 0 for the
	## first piece, or -1 for an empty square. Square 0 is a1 and 63 is h8.
	board : Tape -> List(I8)
	board = |Tape.(tape)| tape.board

	## How many pieces the display shows.
	pieces_shown : Tape -> U64
	pieces_shown = |Tape.(tape)| tape.pieces_shown

	## How many pieces mean the search is solved.
	target_count : Tape -> U64
	target_count = |Tape.(tape)| tape.target_count

	## How many moves the display has applied.
	cursor : Tape -> U64
	cursor = |Tape.(tape)| tape.cursor

	## How many moves the search has made.
	move_count : Tape -> U64
	move_count = |Tape.(tape)| tape.events.len()

	## The most pieces the search has had on the board at once, whatever the
	## display shows: the closest it has come.
	deepest : Tape -> U64
	deepest = |Tape.(tape)| tape.deepest

	## Where the search stands at the tape's end.
	search : Tape -> Tape.Search
	search = |Tape.(tape)| tape.search

	## The square of the newest piece shown, the search's frontier.
	head : Tape -> Try(U8, [EmptyBoard])
	head = |Tape.(tape)|
		if tape.pieces_shown == 0 {
			Err(EmptyBoard)
		} else {
			newest = move_number(tape.pieces_shown - 1)
			match tape.board.find_first_index(|number| number == newest) {
				Ok(square) => Ok(square.to_u8_wrap())
				Err(NotFound) => crash "Tape.head: pieces are shown and none holds the newest number"
			}
		}

	## Each square's dead-end mark, in square order: the square is empty and a
	## piece placed there has been retracted.
	dead_ends : Tape -> List(Bool)
	dead_ends = |Tape.(tape)|
		List.map2(tape.board, tape.touches, |number, touched| number < 0 and touched > 0)

	is_eq : _
}

The Knight's Tour machine: the move graph, the tour as a puzzle, and the squares cut off from the tour.

## Knight is the Knight's Tour machine: a depth-first search for a path
## that visits all 64 squares exactly once, a knight's move at a time. The
## backtracking, the tape, the display and the dead-end overlay are the chess
## kit's; what is knight-shaped is here: the move graph, the tour as a puzzle
## for the kit's search, and which squares the tour can no longer reach.
##
## Each square's moves are tried in order of how few onward moves their
## target has, fewest first, ties in the order the graph lists them: a
## frozen Warnsdorff. In the plain geometric order the search fails to finish
## from 54 of the 64 starts within 200 million moves; in this one it
## finishes from every start, within 2,520,884 moves from g6, the worst, and
## with no backtracking at all from b2. KnightProof.roc holds every start's
## count.
import chess.Backtrack
import chess.Tape

## The backtracking search for a tour, and the square of its first knight,
## which comes off when no tour is left to try.
Knight :: { search : Backtrack(Knight.PartialTour), first : U8 }.{

	## Where a partial tour stands: the newest knight's square, and the squares
	## the tour covers, a bit each.
	PartialTour : { square : U8, visited : U64 }

	## The tour's first knight, on `square`.
	start : U8 -> Knight
	start = |square| {
		search = Backtrack.start({ square, visited: square_bit(square) })
		Knight.({ search, first: square })
	}

	## The search one transition on: the newest knight's next untried move to
	## an empty square, or, with none left, that knight taken off.
	next_move : Knight -> (Knight, Tape.Move)
	next_move = |Knight.({ search, first })| {
		(stepped, step) = search.step(tour)
		move =
			match step {
				Entered({ square, .. }) => Place(square)
				Left({ square, .. }) => Remove(square)
				Exhausted => RemoveAndGiveUp(first)
			}
		(Knight.({ search: stepped, first }), move)
	}

	## Each empty square the tour can never enter from where it stands: no
	## path of empty squares joins it to the newest knight. Where the newest
	## knight has no empty neighbour, every empty square is, and the search is
	## about to back up.
	impossible_squares : Tape -> List(Bool)
	impossible_squares = |tape| {
		board = tape.board()
		match tape.head() {
			Err(EmptyBoard) => List.repeat(Bool.False, 64)
			Ok(head) => {
				reached = squares_reached(board, head)
				is_reached = |square| U64.bitwise_and(reached, square_bit(square.to_u8_wrap())) != 0
				board.map_with_index(|number, square| number < 0 and !is_reached(square))
			}
		}
	}

	## The squares a knight reaches from each square, in the order the search
	## tries them.
	moves_from : List(List(U8))
	moves_from = knight_moves
}

square_bit : U8 -> U64
square_bit = |square| U64.shl_wrap(1, square)

## The tour as a puzzle: the option at `index` is the knight's move there in
## the search's order, refused onto a square the tour covers.
tour : Backtrack.Puzzle(Knight.PartialTour)
tour = |{ square, visited }, index| {
	span = landing_spans.get(square.to_u64()) ?? crash "Knight.tour: a square past the board"
	if index >= span.count {
		End
	} else {
		landing = landings_end_to_end.get(span.offset + index) ?? crash "Knight.tour: a move inside its square's span"
		if U64.bitwise_and(visited, square_bit(landing)) != 0 {
			Refused
		} else {
			Child({ square: landing, visited: U64.bitwise_or(visited, square_bit(landing)) })
		}
	}
}

## Every square's knight moves end to end, the squares in order and each
## square's moves in the search's order. The search reads a move here rather
## than from the square's own list in `knight_moves`, whose reference count,
## taken for every option tried, costs a fifth of the tour's time.
landings_end_to_end : List(U8)
landings_end_to_end = knight_moves.join()

## Where each square's moves sit in `landings_end_to_end`.
landing_spans : List({ offset : U64, count : U64 })
landing_spans = {
	var $offset = 0
	var $spans = []
	for landings in knight_moves {
		$spans = $spans.append({ offset: $offset, count: landings.len() })
		$offset = $offset + landings.len()
	}
	$spans
}

## The empty squares a flood reaches from `head` through empty squares, a bit
## each.
squares_reached : List(I8), U8 -> U64
squares_reached = |move_numbers, head| {
	is_empty = |square| (move_numbers.get(square.to_u64()) ?? crash "Knight.squares_reached: a square past the board") < 0
	var $reached = 0
	var $frontier = [head]
	while !$frontier.is_empty() {
		square = $frontier.last() ?? crash "Knight.squares_reached: the frontier is not empty"
		$frontier = $frontier.drop_last(1)
		for target in knight_moves.get(square.to_u64()) ?? crash "Knight.squares_reached: a square past the board" {
			if is_empty(target) and U64.bitwise_and($reached, square_bit(target)) == 0 {
				$reached = U64.bitwise_or($reached, square_bit(target))
				$frontier = $frontier.append(target)
			}
		}
	}
	$reached
}

## Every square's knight moves, each list in the search's order.
knight_moves : List(List(U8))
knight_moves = {
	geometric = List.from_iter(U64.until(0, 64)).map(geometric_moves)
	geometric.map(|landings| landings_by_fewest_onward(landings, geometric))
}

## The squares a knight reaches from `square`, in the order the deltas
## below go round.
geometric_moves : U64 -> List(U8)
geometric_moves = |square| {
	rank = square.to_i64_wrap() // 8
	file = square.to_i64_wrap() % 8
	deltas = [
		(1, 2),
		(2, 1),
		(2, -1),
		(1, -2),
		(-1, -2),
		(-2, -1),
		(-2, 1),
		(-1, 2),
	]
	var $landings = []
	for (rank_step, file_step) in deltas {
		to_rank = rank + rank_step
		to_file = file + file_step
		if to_rank >= 0 and to_rank <= 7 and to_file >= 0 and to_file <= 7 {
			$landings = $landings.append((to_rank * 8 + to_file).to_u8_wrap())
		}
	}
	$landings
}

## `landings` in order of how many moves each has in `landing_lists`, a list a
## square, fewest first; the sort is an insertion sort, so ties keep their
## order.

## attacking another. The backtracking, the tape, the display and the
## dead-end overlay are the chess kit's; what is queen-shaped is here: the
## puzzle the kit's search solves, and which squares are attacked.
##
## The click pins the first queen. It is move 0, it is never retracted, and
## the search fills the other seven rows in order around it, one queen a row
## by construction, so it branches only on columns: the classic depth-first
## search, trying the next column in this row that no queen attacks, and
## with none left taking the previous row's queen back off and resuming from
## its next column. Every square of the board is on some solution, so no pin
## exhausts; QueensProof.roc holds every pin's count.
import chess.Backtrack
import chess.Tape

## The backtracking search for a solution.
Queens :: Backtrack(Queens.PartialSolution).{

	## Where a partial solution stands: the newest queen's square, the pin's
	## row, how many other rows hold a queen, and the columns and the two
	## families of diagonals the queens on the board, the pin among them,
	## attack, a bit each.
	PartialSolution : {
		square : U8,
		pin_row : U8,
		rows_filled : U8,
		columns : U16,
		sums : U16,
		differences : U16,
	}

	## The search with its pinned queen on `square`.
	start : U8 -> Queens
	start = |square| {
		empty = {
			square,
			pin_row: square // 8,
			rows_filled: 0,
			columns: 0,
			sums: 0,
			differences: 0,
		}
		Queens.(Backtrack.start(with_attacks(empty, square)))
	}

	## The search one transition on: a queen in the next open column of the
	## row being filled, or, with none, the previous row's queen taken off.
	next_move : Queens -> (Queens, Tape.Move)
	next_move = |Queens.(search)| {
		(stepped, step) = search.step(solution)
		move =
			match step {
				Entered({ square, .. }) => Place(square)
				Left({ square, .. }) => Remove(square)
				Exhausted => GiveUp
			}
		(Queens.(stepped), move)
	}

	## Each empty square a queen on the board attacks, along a row, a column
	## or a diagonal, whatever stands between: no queen can live there now.
	impossible_squares : Tape -> List(Bool)
	impossible_squares = |tape| {
		board = tape.board()
		numbered = board.map_with_index(|number, square| (number, square.to_u8_wrap()))
		queens = numbered.keep_if(|(number, _)| number >= 0).map(|(_, square)| square)
		is_under_attack = |square| queens.any(|queen| is_attack(queen, square))
		board.map_with_index(|number, square| number < 0 and is_under_attack(square.to_u8_wrap()))
	}

	## The squares a queen on each square attacks, in square order.
	moves_from : List(List(U8))
	moves_from = squares.map(|from| squares.keep_if(|to| to != from and is_attack(from, to)))
}

## Whether queens on the two squares share a row, a column or a diagonal.
is_attack : U8, U8 -> Bool
is_attack = |from, to| {
	from_row = (from // 8).to_i64()
	from_column = (from % 8).to_i64()
	to_row = (to // 8).to_i64()
	to_column = (to % 8).to_i64()
	from_row == to_row
		or from_column == to_column
		or from_row + from_column == to_row + to_column
		or from_row - from_column == to_row - to_column
}

## Eight Queens as a puzzle: the option at `index` is that column of the next
## row to fill, refused where a queen attacks it.
solution : Backtrack.Puzzle(Queens.PartialSolution)
solution = |position, index|
	if index >= 8 {
		End
	} else {
		square = next_row(position) * 8 + index.to_u8_wrap()
		if is_attacked(position, square) {
			Refused
		} else {
			Child({
				..with_attacks(position, square),
				square,
				rows_filled: position.rows_filled + 1,
			})
		}
	}

## The row the search fills next: the rows in order, the pin's left out.
next_row : Queens.PartialSolution -> U8
next_row = |{ pin_row, rows_filled, .. }|
	if rows_filled >= 7 {
		crash "Queens.next_row: every row is filled, and the search is solved then"
	} else if rows_filled < pin_row {
		rows_filled
	} else {
		rows_filled + 1
	}

## The position with a queen on `square` added to its attacks, or, where one
## is there, taken out: each bit flips.
with_attacks : Queens.PartialSolution, U8 -> Queens.PartialSolution
with_attacks = |position, square| {
	row = square // 8
	column = square % 8
	{
		..position,
		columns: U16.bitwise_xor(position.columns, U16.shl_wrap(1, column)),
		sums: U16.bitwise_xor(position.sums, U16.shl_wrap(1, row + column)),
		differences: U16.bitwise_xor(position.differences, U16.shl_wrap(1, row + 7 - column)),
	}
}

## Whether a queen on the board attacks `square`, along its column or a
## diagonal; the search never puts two queens in a row.
is_attacked : Queens.PartialSolution, U8 -> Bool
is_attacked = |position, square| {
	row = square // 8
	column = square % 8
	U16.bitwise_and(position.columns, U16.shl_wrap(1, column)) != 0
		or U16.bitwise_and(position.sums, U16.shl_wrap(1, row + column)) != 0
		or U16.bitwise_and(position.differences, U16.shl_wrap(1, row + 7 - column)) != 0
}

// The page owns it and the game is told. Every tick carries two bit sets:
// which keys are down now, and which went down since the last tick. A game
// needs both — snake turns on the edge, a paddle moves while a key is held —
// so an event alone will not do.

const KEY_BIT = {
  ArrowUp: 1, ArrowDown: 2, ArrowLeft: 4, ArrowRight: 8,
  KeyW: 16, KeyA: 32, KeyS: 64, KeyD: 128,
  Space: 256, Enter: 512, KeyP: 1024, KeyR: 2048,

function watchKeyboard(target) {
  const held = new Set();
  let struck = new Set();
  // A shortcut belongs to the browser: Ctrl+R reloads, Ctrl+F finds.
  const known = (event) => event.code in KEY_BIT && !(event.ctrlKey || event.metaKey || event.altKey);

  target.addEventListener('keydown', (event) => {
    if (!known(event)) return;
    if (!event.repeat) struck.add(event.code);
    held.add(event.code);
    event.preventDefault();
  });
  target.addEventListener('keyup', (event) => {
    if (!known(event)) return;
    held.delete(event.code);
    event.preventDefault();
  });

  target.addEventListener('blur', () => { held.clear(); struck.clear(); });

  return () => {
    const snapshot = { held: maskOf(held), struck: maskOf(struck) };
    struck = new Set();
    return snapshot;
  };

// A mouse, a finger and a pen all arrive as pointer events, so an app can't
// tell them apart. Position is reported in the game's own coordinates, so a
// game never learns how big the window is or how the page scaled the canvas.
// During a drag it may be off the canvas.

// `event.buttons` uses Mouse.roc's bits, and safari/gates/input_bits.shale holds the
// two equal, as it does KEY_BIT.
const MOUSE_BIT = { Left: 1, Right: 2, Middle: 4 };
const MOUSE_BITS = MOUSE_BIT.Left | MOUSE_BIT.Right | MOUSE_BIT.Middle;

function watchPointer(canvas, width, height) {
  let held = 0;
  let struck = 0;
  let at = { x: 0, y: 0 };
  let wheel = 0;
  // The pointer that pressed on the canvas, until it lets go. A second finger
  // is ignored until then.
  let dragger = null;

  const place = (event) => {
    const box = canvas.getBoundingClientRect();
    at = {
      x: ((event.clientX - box.left) / box.width) * width,
      y: ((event.clientY - box.top) / box.height) * height,
    };
  };

  const readButtons = (event) => {
    const now = event.buttons & MOUSE_BITS;
    struck |= now & ~held;
    held = now;
  };

  const release = (event) => {
    if (event.pointerId !== dragger) return;
    held = 0;
    dragger = null;
  };

  canvas.addEventListener('pointerdown', (event) => {
    if (dragger !== null && event.pointerId !== dragger) return;
    dragger = event.pointerId;
    // With capture, a drag that leaves the canvas keeps tracking and ends here.
    canvas.setPointerCapture(dragger);
    place(event);
    readButtons(event);
    event.preventDefault();
  });
  canvas.addEventListener('pointermove', (event) => {
    if (dragger !== null && event.pointerId !== dragger) return;
    place(event);
    // A mouse's other buttons arrive as moves: pointerdown and pointerup come
    // only with the first button down and the last one up.
    if (dragger !== null) readButtons(event);
  });
  canvas.addEventListener('pointerup', release);
  canvas.addEventListener('pointercancel', release);
  canvas.addEventListener('contextmenu', (event) => event.preventDefault());
  // Positive is away from the hand, as raylib reports it; a browser's deltaY
  // is the other way round.
  canvas.addEventListener('wheel', (event) => { wheel -= Math.sign(event.deltaY); event.preventDefault(); });
  window.addEventListener('blur', () => { held = 0; struck = 0; dragger = null; });

  return () => {
    const pointer = { held, struck, x: at.x, y: at.y, wheel };
    struck = 0;
    wheel = 0;
    return pointer;
  };

// One oscillator per sound, gated to nothing quickly enough not to click.
function makeSpeaker(game) {
  let audio = null;
  const tones = [...Array(game.toneCount()).keys()].map((i) => ({
    freq: game.toneFreq(i),
    seconds: game.toneMs(i) / 1000,
  }));

  const wake = () => {
    if (typeof AudioContext === 'undefined') return;
    audio ??= new AudioContext();
    audio.resume();
  };

  const play = (which) => {
    if (!audio) return;
    for (const index of which) {
      const tone = tones[index];
      if (!tone) continue;
      const osc = audio.createOscillator();
      const gain = audio.createGain();
      osc.frequency.value = tone.freq;
      gain.gain.setValueAtTime(0.18, audio.currentTime);
      gain.gain.exponentialRampToValueAtTime(0.001, audio.currentTime + tone.seconds);
      osc.connect(gain).connect(audio.destination);
      osc.start();
      osc.stop(audio.currentTime + tone.seconds);
    }
  };

  return { wake, play, count: tones.length };
}

// With `?timing=1` in the address, the first frames' times go to the console:
// how long the wasm took to load and compile and to take its opening presses,
// then per frame the gap since the last one, the steps taken, and the
// milliseconds spent stepping and drawing. Comparing the first TIMED_WINDOW of
// the TIMED_FRAMES frames with the last tells a slow start (the engine still on
// its first, unoptimized code) from a slow ride. Without it nothing is
// recorded.
const TIMED_FRAMES = 120;
const TIMED_WINDOW = 30;
function frameTimer() {
  if (new URLSearchParams(location.search).get('timing') !== '1') return null;
  const rows = [];
  const first = [0, TIMED_WINDOW];
  const last = [TIMED_FRAMES - TIMED_WINDOW, TIMED_FRAMES];
  return {
    loaded: (ms) =>
      console.log(`canvas_app_runner: wasm loaded, compiled and through its opening presses in ${ms.toFixed(0)} ms`),
    frame: (row) => {
      if (rows.length >= TIMED_FRAMES) return;
      rows.push(row);
      if (rows.length < TIMED_FRAMES) return;
      console.table(rows);
      const slow = (from, to) => rows.slice(from, to).filter((r) => r.stepMs + r.drawMs > 16).length;
      const mean = (from, to, key) =>
        (rows.slice(from, to).reduce((sum, r) => sum + r[key], 0) / (to - from)).toFixed(1);
      const steps = (from, to) => rows.slice(from, to).reduce((sum, r) => sum + r.steps, 0);
      console.log(
        `canvas_app_runner: frames over 16 ms of work: first ${TIMED_WINDOW} ${slow(...first)}, ` +
          `last ${TIMED_WINDOW} ${slow(...last)}; ` +
          `mean step ms ${mean(...first, 'stepMs')} then ${mean(...last, 'stepMs')}, ` +
          `mean draw ms ${mean(...first, 'drawMs')} then ${mean(...last, 'drawMs')} ` +
          `(wasm ${mean(...first, 'computeMs')} then ${mean(...last, 'computeMs')}, ` +
          `decode ${mean(...first, 'decodeMs')} then ${mean(...last, 'decodeMs')}, ` +
          `paint ${mean(...first, 'paintMs')} then ${mean(...last, 'paintMs')}), ` +
          `steps taken ${steps(...first)} then ${steps(...last)}`,
      );
    },
  };
}

      key_struck: keys.struck,
      button_held: mouse.held,
      button_struck: mouse.struck,
      x: mouse.x,
      y: mouse.y,
      wheel: mouse.wheel,
    });

      speaker.play(ringing.tones);
    }

  // size clears it and its transform, so only a change of size sets it.
  const matchScreen = () => {
    const across = Math.round(canvas.getBoundingClientRect().width * (window.devicePixelRatio ?? 1));
    if (across > 0 && across !== canvas.width) {
      canvas.width = across;
      canvas.height = Math.round((across * height) / width);
    }
    const scale = canvas.width / width;
    ctx.setTransform(scale, 0, 0, scale, 0, 0);
    return scale;

  // are taken as they fall due.

  let last = performance.now();

    const gap = now - last;
    owed = Math.min(owed + gap, stepMs * CATCH_UP);
    last = now;
    let stepped = 0;
    const stepStart = performance.now();

      steps: stepped,

      decodeMs: stepped ? +FRAME_SPLIT.decodeMs.toFixed(1) : 0,
      paintMs: stepped ? +FRAME_SPLIT.paintMs.toFixed(1) : 0,
    });

  // clears to black before it decodes, so an uncaught error would leave the
  // page black and silent. So each tick's error stops the page with its
  // message: an unknown brush mode, a Roc crash arriving as `unreachable`.
  // `main`'s catch can't help, because it settled at startup.
  const loop = (now) => {
    try {
      tick(now);
    } catch (error) {
      stopped(error);
      return;
    }
    requestAnimationFrame(loop);
  };

    canvas.remove();
    document.body.textContent = `${show.wasm} stopped: ${error.message}`;

  }

  timer?.loaded(performance.now() - loadStart);

  loading.remove();
  document.body.appendChild(canvas);
  try {
    draw(performance.now());
  } catch (error) {
    stopped(error);
    return;
  }
  last = performance.now();
  requestAnimationFrame(loop);
}

// shapes_canvas.js paints a frame's shapes onto a browser canvas, for every
// canvas app. The shapes are lib/Shapes.roc's `Shape`, which the platform names
// as what a frame is; roc_glue.js, generated by `roc glue` from
// that type, reads them out of the wasm, and this file does what a canvas
// does with them. It answers one name, `ShapesCanvas`, with `paint`.
//
// Its Roc twin is safari/gates/proof/ShapesPixels.roc, which paints the same shapes into
// exact pixels, with no anti-aliasing, for Safari's gate. The gate checks the
// twin, not this file, since Roc can't run a canvas. This file is checked by
// page_check.mjs, which runs every built page against a stand-in canvas, and
// by camera_check.mjs, which checks where a view mark puts points, and by
// text_check.mjs, which checks how a line of type is set.

const stopAt = (offset, floor = 0) => Math.max(floor, Math.min(1, offset));
const channel = (v) => Math.max(0, Math.min(255, Math.round(v)));
const cssColor = (c) => `rgba(${channel(c.r)},${channel(c.g)},${channel(c.b)},${c.a})`;

const withStops = (gradient, stops) => {
  stops.forEach(([offset, color]) => gradient.addColorStop(offset, color));
  return gradient;
};

// Brush.mix, operation for operation, so a colour's last bit agrees with lib's.
const mix = (p, q, t) => ({
  r: p.r + (q.r - p.r) * t, g: p.g + (q.g - p.g) * t,
  b: p.b + (q.b - p.b) * t, a: p.a + (q.a - p.a) * t,
});

// Brush's two_stop: the colour the stops give at t, for t in [0, 1].
const twoStopAt = (s, t) => t <= s.start_offset ? s.start_color
  : t >= s.end_offset ? s.end_color
  : mix(s.start_color, s.end_color, (t - s.start_offset) / (s.end_offset - s.start_offset));

// A canvas takes offsets in [0, 1] only. An offset past either end becomes a
// stop at that end in the colour BrushShade.shade gives there, so the gradient
// matches lib's mix across the whole of [0, 1].
const twoStops = (s) => [
  [stopAt(s.start_offset), cssColor(s.start_offset >= 0 ? s.start_color : twoStopAt(s, 0))],
  [stopAt(s.end_offset, stopAt(s.start_offset)), cssColor(s.end_offset <= 1 ? s.end_color : twoStopAt(s, 1))],
];

// A fill becomes something canvas can paint with. An ellipse is the exception:
// it paints through a transform, so it stays a descriptor.
function paintFor(ctx, fill) {
  const p = fill.value;
  switch (fill.tag) {
    case "Flat":
      return cssColor(p);
    case "Span":
      // BrushShade.shade's t is 1 when the edges meet, all the way from the middle
      // colour to the edge colour.
      if (p.right_x === p.left_x) return cssColor(mix(p.middle_color, p.edge_color, 1));
      return withStops(ctx.createLinearGradient(p.left_x, 0, p.right_x, 0),
        [[0, cssColor(p.edge_color)], [0.5, cssColor(p.middle_color)], [1, cssColor(p.edge_color)]]);
    case "Radial":
      // With no ring to walk, BrushShade.shade mixes all the way to the outer colour.
      if (!(p.outer_radius > p.inner_radius)) return cssColor(mix(p.inner_color, p.outer_color, 1));
      return withStops(ctx.createRadialGradient(p.center.x, p.center.y, p.inner_radius, p.center.x, p.center.y, p.outer_radius),
        [[0, cssColor(p.inner_color)], [1, cssColor(p.outer_color)]]);
    case "Linear": {
      const dx = p.end_point.x - p.start_point.x;
      const dy = p.end_point.y - p.start_point.y;
      if (!(dx * dx + dy * dy > 0)) return cssColor(twoStopAt(p.stops, 1));
      return withStops(ctx.createLinearGradient(p.start_point.x, p.start_point.y, p.end_point.x, p.end_point.y),
        twoStops(p.stops));
    }
    case "Glow":
      // With no ring to walk, BrushShade.shade takes t = 1, past the middle offset,
      // and mixes from the middle colour to the outer one.
      if (!(p.outer_radius > p.inner_radius)) {
        return cssColor(mix(p.middle_color, p.outer_color, (1 - p.middle_offset) / (1 - p.middle_offset)));
      }
      return withStops(ctx.createRadialGradient(p.center.x, p.center.y, p.inner_radius, p.center.x, p.center.y, p.outer_radius),
        [[0, cssColor(p.inner_color)], [p.middle_offset, cssColor(p.middle_color)], [1, cssColor(p.outer_color)]]);
    case "Ellipse":
      return { ellipse: p };
    default:
      throw new Error(`shapes_canvas: no brush ${fill.tag}`);
  }
}

// An ellipse brush carries its axes, the matrix that takes the unit circle to
// the ellipse, which is the transform a canvas wants.
function fillThroughEllipse(ctx, p) {
  ctx.save();
  ctx.clip();
  ctx.transform(p.axis_u.x, p.axis_u.y, p.axis_v.x, p.axis_v.y, p.center.x, p.center.y);
  ctx.fillStyle = withStops(ctx.createRadialGradient(0, 0, 0, 0, 0, 1), twoStops(p.stops));
  ctx.fillRect(-1e4, -1e4, 2e4, 2e4); // clipped to the path; past r=1 the gradient holds
  ctx.restore();
}

function fillShape(ctx, fill) {
  const paint = paintFor(ctx, fill);
  if (paint.ellipse) fillThroughEllipse(ctx, paint.ellipse);
  else { ctx.fillStyle = paint; ctx.fill(); }
}

// A triangle, a quad and a polygon are traced alike, as the path round their
// corners in order.
function tracePolygon(ctx, corners) {
  ctx.beginPath();
  ctx.moveTo(corners[0].x, corners[0].y);
  for (let i = 1; i < corners.length; i++) ctx.lineTo(corners[i].x, corners[i].y);
  ctx.closePath();
}

// Where the shapes after a view mark are: the camera written as the matrix a
// canvas takes. Camera.world_to_screen does this in Roc, BeginMode2D in raylib.
// `scale` is how many canvas pixels the app's own pixel takes.
function setSpace(ctx, space, scale) {
  if (space.tag === "Screen") { ctx.setTransform(scale, 0, 0, scale, 0, 0); return; }
  const c = space.value;
  const radians = (c.rotation * Math.PI) / 180;
  const cos = Math.cos(radians) * c.zoom;
  const sin = Math.sin(radians) * c.zoom;
  ctx.setTransform(scale * cos, scale * sin, -scale * sin, scale * cos,
    scale * (c.offset.x - (c.target.x * cos - c.target.y * sin)),
    scale * (c.offset.y - (c.target.x * sin + c.target.y * cos)));
}

function paintImage(ctx, p) {
  if (!p.cols || !p.rows) return;
  if (!scratch.canvas) {
    scratch.canvas = document.createElement('canvas');
    scratch.ctx = scratch.canvas.getContext('2d');
  }
  if (scratch.canvas.width !== p.cols || scratch.canvas.height !== p.rows) {
    scratch.canvas.width = Number(p.cols);
    scratch.canvas.height = Number(p.rows);
  }
  const image = scratch.ctx.createImageData(Number(p.cols), Number(p.rows));
  const bytes = image.data;
  for (let i = 0; i < p.pixels.length; i++) {
    const c = p.pixels[i];
    bytes[i * 4] = channel(c.r);
    bytes[i * 4 + 1] = channel(c.g);
    bytes[i * 4 + 2] = channel(c.b);
    bytes[i * 4 + 3] = channel(c.a * 255);
  }
  scratch.ctx.putImageData(image, 0, 0);
  const smoothing = ctx.imageSmoothingEnabled;
  ctx.imageSmoothingEnabled = false;
  ctx.drawImage(scratch.canvas, 0, 0, Number(p.cols), Number(p.rows), p.x, p.y, p.width, p.height);
  ctx.imageSmoothingEnabled = smoothing;
}

function paintFrame(ctx, shapes, scale = 1) {
  for (const shape of shapes) {
    const p = shape.value;
    switch (shape.tag) {
      // The two marks are not shapes: one says how the shapes after it
      // combine, the other says where they are.
      case "Blend":
        ctx.globalCompositeOperation = p.tag === "Add" ? 'lighter' : 'source-over';
        break;
      case "View":
        setSpace(ctx, p, scale);
        break;
      case "Image":
        paintImage(ctx, p);
        break;
      case "Text":
        paintText(ctx, p);
        break;
      case "Triangle":
        tracePolygon(ctx, [p.first, p.second, p.third]);
        fillShape(ctx, p.fill);
        break;
      case "Quad":
        tracePolygon(ctx, [p.first, p.second, p.third, p.fourth]);
        fillShape(ctx, p.fill);
        break;
      case "Polygon":
        tracePolygon(ctx, p.corners);
        fillShape(ctx, p.fill);
        break;
      case "Disc":
        ctx.beginPath();
        ctx.arc(p.center.x, p.center.y, p.radius, 0, Math.PI * 2);
        ctx.closePath();
        fillShape(ctx, p.fill);
        break;
      default:
        throw new Error(`shapes_canvas: no shape ${shape.tag}`);
    }
  }
  ctx.globalCompositeOperation = 'source-over';
  ctx.setTransform(scale, 0, 0, scale, 0, 0);
}
