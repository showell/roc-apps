# What may hold a bare F64 in safari. The rule is in docs/roc-style.md, and
# cookbook/roc/bare_floats.shale reads this table.

# The unit types: each module's job is holding the float.
Acceleration: a unit type
Across: a unit type
Along: a unit type
Angle: the unit types for bearings, turns and leans
Attention: a unit type
Beat: a unit type
Beats: a unit type
CatHeights: a unit type
Distance: a unit type
Fraction: a unit type
Pixels: a unit type
Speed: a unit type
Clock.to_f64: a whole count's way into float sums
Steps.to_f64: a whole count's way into float sums

# Factors and ratios, which have no unit.
Bike.turn_per_lean: a turn per radian of lean, an angle over an angle
ViewYaw.head_turn_per_lean: a turn per radian of lean, an angle over an angle
LeanSearch.asymptote_tuning: a tuning factor on a length
DepthSort.tie_slack: a relative tolerance, scaled by the length it is compared with
TruckLights.glow_reach: a factor that passes 1
Paint.shade_channel: a factor that passes 1 on a colour channel
Paint.shade_color: a factor that passes 1 on a colour
StillDraw.x_sign: a sign, 1 or -1, multiplied into a still's x
Tower.corner_offset: a sign, 1 or -1, for each way a corner lies from the centre
Mountains.MountainRange: how many ridge waves fit a whole turn, a frequency
Easing.lerp: the sum behind blending any unit, which a caller unwraps once
Animation.Timeline: `times` in the where clause takes a plain factor
Animation.path_spot: `times` in the where clause takes a plain factor
Animation.line_spot: `times` in the where clause takes a plain factor

# Numbers with a meaning no unit type here holds.
Sky.Rgb: a colour's channels, part way through a blend
Sky.whole_channel: one of a colour's channels, part way through a blend
Paint.min_ellipse_determinant: square pixels, the plain number two axes' determinant gives
VehicleLimits.turn_speeds: whole degrees, a key looked up by equality after a turn rounds to it
Stills: traced pictures, in units of the still's own height

# Trigonometry.
TreeDraw.ring_angles: radians for Trig
TruckShape.circle_angles: radians for Trig

# The edge of lib.Shapes, which takes plain numbers.
Screen.point: the plain numbers a point is written with, on the way into Pixels
Paint.flatten_screen: the flat list lib.Shapes takes
Paint.ColorStops: gradient offsets as traced, which offsets_of holds to 0 to 1
Paint.offsets_of: the gradient offsets lib.Shapes takes

# The gates: test code, and the raster past lib.Shapes.
CrossModuleExpects: an app holding only expects and their helpers
PixelColor: raster code past lib.Shapes, where numbers are plain
PixelGrid: raster code past lib.Shapes, where numbers are plain
ScanlineFill: raster code past lib.Shapes, where numbers are plain
ScreenRoll: raster code past lib.Shapes, where numbers are plain
ShapesPixels: raster code past lib.Shapes, where numbers are plain
