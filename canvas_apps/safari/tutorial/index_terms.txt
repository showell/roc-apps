# The book's index terms. tutorial/book_index.shale finds each term in the
# prose of the built book, chapter by chapter.
#
# A line `## Category` starts a category. Every other line that isn't blank or
# a `#` comment is `term | pattern | pattern …`. A pattern is a regular
# expression matched against a line of prose in lower case, code spans and
# all, so a backticked keyword is written with its backticks. A term with no
# pattern is found by its own name, as a whole word.
#
# A term's main chapter is the one that mentions it most. A part `main: Title`
# names it instead, where the count picks a chapter that only passes through,
# and the script stops if that chapter never mentions the term.
