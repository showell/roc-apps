# Roc's own words, which the parser's tree holds as syntax and not as names.
_: Roc's wildcard, in a pattern or an annotation
app: a Roc keyword, the header of an app
crash: a Roc keyword
expect: a Roc keyword
for: a Roc keyword
if: a Roc keyword
in: a Roc keyword, in a for loop
import: a Roc keyword
match: a Roc keyword
var: a Roc keyword
where: a Roc keyword, in an annotation
while: a Roc keyword

# Roc's builtins, which the book calls by their full names.
F64.pi: a Roc builtin, the constant pi
U32.until: a Roc builtin
U64.until: a Roc builtin

List.repeat: a Roc builtin
List.with_capacity: a Roc builtin

# Roc's command line.
roc: the Roc command
test: the `roc test` command
PASS: what `roc test --verbose` prints for an expect

shapes_canvas.js: a file of the JavaScript platform
