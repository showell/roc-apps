# Allocations and reallocations an iteration each control is held to in the
# release build (--opt=speed), and why when either is not 0:
# `<control> <allocs> <reallocs> <why>`. A control not listed here is held to
# 0 and 0. Measured on Roc 0.1.0-RC1 by basic/controls.shale.
12-def-fn 1 0 a call binds its parameter by appending to a list of bindings (strace -k on the old nightly: list_reserve)
20-print-loop 1 0 PRINT turns its line into bytes to draw it (Str.to_utf8); the builtins have no byte walk over a Str
21-string-grow 1 0 the string grows by one byte an iteration
23-print-semicolon 1 0 PRINT turns its text into bytes to draw it (Str.to_utf8), as 20-print-loop does
34-print-tab 1 0 PRINT turns its text into bytes to draw it (Str.to_utf8); the TAB adds nothing
38-input 3 0 two Str.to_utf8 and one list growing an iteration (strace -k on the old nightly); the list_replace and the copy the old nightly added since the devices moved behind one reference are gone on RC1
49-print-trim 20 0 twenty PRINTs an iteration, each a Str.to_utf8; trimming the transcript adds one allocation each 8,000 pieces, under 0.01 an iteration
