BASIC, in Roc

An ECMA-55 Minimal BASIC interpreter, hand-written in Roc, compiled to WebAssembly. Everything below runs in this tab.


  






  The interpreter is one Roc module with no dependencies. A run is a pure function of the
  listing, the keystrokes and a seed, so the page hands over three buffers and reads one back.
  Graded against the National Bureau of Standards' Minimal BASIC test programs and the 1978
  BASIC Computer Games listings.
